# 🚀 Space Mission Analysis | Power BI

## 📌 Overview

An interactive Power BI dashboard built to analyze global space mission data and uncover insights about launch performance, mission success rates, leading organizations, and country-wise launch activity.

---

## 🛠️ Tools Used

- Power BI Desktop
- Power Query
- DAX
- Data Visualization

---

## 📂 Files Included

| File | Description |
|---|---|
| Space_Mission_Performance_Dashboard.pbix | Power BI dashboard file |
| Space_Corrected.csv | Space mission dataset |
| README.md | Project documentation |

---

## 📊 Dashboard Insights

- Total number of space missions
- Mission success rate analysis
- Year-wise launch trends
- Top launch providers
- Country-wise launch comparison
- Mission status distribution

---

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Explore the dashboard using filters and interactive visuals.
